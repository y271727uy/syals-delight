# Syal's delight

Minecraft 1.21.1 Fabric 移植，内容对齐上游 `1.21.1`（NeoForge）分支。

- Mod ID：`syals_delight`
- 包名：`com.y271727uy.syals_delight`
- Java：21
- Fabric Loader：0.19.5
- Fabric API：0.116.17+1.21.1

本地编译时把 Gradle 用户目录固定在 D 盘：

```
$env:GRADLE_USER_HOME = 'D:\document\dev\gradle\.gradle'
.\gradlew.bat --no-daemon compileJava
```
