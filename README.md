Installation information
=======

This project uses the Forge 1.12.2 development environment based on [RetroFuturaGradle](https://github.com/GTNewHorizons/RetroFuturaGradle).

Run Gradle with Java 25 or newer; the mod itself is compiled for Java 8. The project uses the MCP stable 39 mappings for Minecraft 1.12.2. Available development tasks include `runClient`, `runServer`, and `reobfJar`.

If your IDE is missing dependencies, run `gradlew --refresh-dependencies`. Run `gradlew clean` to reset generated build outputs without affecting source code.
